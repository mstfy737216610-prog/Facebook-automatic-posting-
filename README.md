# AdMan Facebook - نشر متعدد الحسابات على مجموعات فيسبوك (مشروع منفصل)

مشروع مستقل تمامًا عن `Twitter_Telegram_Bot` (قاعدة بياناته وجلساته وإعداداته منفصلة). مصمم لأصحاب مكاتب الخدمات الطلابية.

## ماذا يفعل
1. **اكتشاف المجموعات**: يبحث في فيسبوك بالكلمات المفتاحية (ماجستير، دكتوراه، خدمات طلابية...) ويخزن المجموعات مع فئتها - **تُخزن في الذاكرة ولا يعيد البحث عنها**.
2. **اعتمد/استبعد**: أنت تعتمد المجموعات المناسبة من الواجهة وتصنفها.
3. **مكتبة منشورات**: منشوراتك مصنفة حسب الفئة (منشور ماجستير، منشور خدمات...).
4. **حملات نشر متوازية**: زر واحد ينشر منشورات الفئة على كل مجموعاتها المعتمدة، بكل الحسابات المفعّلة، في نفس الوقت، مع **إعادة صياغة ذكية** لكل مجموعة (تجنبًا لفلتر السبام في فيسبوك).

## التثبيت على Termux
```bash
pkg update && pkg upgrade -y
pkg install -y python git
cd Facebook_Bot
pip install -r requirements.txt
playwright install chromium
python3 run.py
```
الواجهة: `http://127.0.0.1:8081` (كلمة المرور الافتراضية `change-me-123` - غيّرها في `config/settings.json`).

## خطوات التشغيل
1. **أضف حساب/حسابات** من تبويب الحسابات (لكل حساب بروكسي خاص اختياري).
2. **ارفع الكوكيز** لكل حساب: سجّل دخول فيسبوك في كروم ← صدّر الكوكيز JSON (إضافة Get cookies.txt LOCALLY) ← ارفعها من الواجهة. تُحفظ في `data/sessions/<id>/cookies.json`.
3. **اكتشاف المجموعات**: زر "🔍 اكتشاف مجموعات" - يجمع ويصنف تلقائيًا (masters/phd/services).
4. **اعتمد المجموعات** وصنّفها إن لزم من تبويب المجموعات.
5. **أضف منشوراتك** للمكتبة مختارًا فئتها (مثلاً منشور ماجستير).
6. **🚀 تشغيل الحملة**: ينشر المنشور على كل مجموعات فئته بكل الحسابات، بإعادة صياغة AI لكل نسخة، وتأخيرات بشرية.

## ملاحظات مهمة
- **لا Graph API** - نشر عبر المتصفح (Playwright) بكوكيزك، كما تفعل أنت تمامًا.
- النشر على المجموعات يتطلب أن تكون عضوًا فيها وحالة الحساب جيدة (غير مقيد).
- حدود التأخير الافتراضية: 90 ثانية بين المجموعات و20 ثانية بين الحسابات - عدّلها في `config/settings.json`.
- البيانات في `data/db/facebook_memory.db` - **الذاكرة**: المجموعات المكتشفة لا تُفقد ولا تتكرر.
- الأتمتة مخالفة لشروط فيسبوك - استخدم بحسابات غير رئيسية وبروكسيات، وراجع `../Twitter_Telegram_Bot/docs/PROXIES.md`.
